Arquitectura MVC en PHP

¿Cómo funciona el código?

Resumen mínimo del flujo de ejecución y los componentes clave del sistema.

Flujo de Ejecución (Paso a Paso)

1

Punto de Entrada public/index.php

Atrapa cada petición mediante el parámetro ?action=... y centraliza el enrutamiento.

2

Seguridad y Permisos

Verifica si existe sesión activa y valida si el rol del usuario (ADMIN, SOCIO, etc.) tiene permiso para esa acción.

3

Controlador src/Controllers/

El router delega la petición al controlador correspondiente para ejecutar la lógica del negocio.

4

Modelo src/Models/

El controlador invoca modelos para consultar o actualizar la base de datos MySQL mediante PDO.

5

Respuesta src/Views/

Muestra la vista en HTML/PHP renderizada o retorna datos en formato JSON si es una llamada AJAX.

Módulos Principales

Socios y Empresas

Gestión de afiliados, cónyuges, puestos de trabajo y relaciones.

Biometría

Captura, verificación de huellas y control de asistencia con lector USB.

Votaciones

Registro de postulados, emisión de votos remotos/presenciales y reportes.

Permisos y Roles

Matriz de acceso granular por perfil de usuario y auditoría.
