Cómo corregir el único vector pendiente (XSS en JSON)

Cuando se imprime un JSON generado por PHP directamente dentro de una etiqueta <script>, si un rol contiene la secuencia </script>, el navegador puede interpretar el fin de la etiqueta antes de tiempo y ejecutar scripts. La solución es usar las banderas nativas de sanitización de PHP:

Línea 5 Actual (Vulnerable a nombres con tags) 
// index.php - línea 5
$roles_json = json_encode($roles_permisos);

// Si un rol se llama: </script><script>alert(1)</script>
// Rompe el bloque <script> del navegador.
Línea 5 Blindada (100% Seguro) 
// index.php - línea 5 (Blindado contra XSS)
$roles_json = json_encode(
    $roles_permisos,
    JSON_HEX_TAG | JSON_HEX_APOS | JSON_HEX_QUOT | JSON_HEX_AMP
);
